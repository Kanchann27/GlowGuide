# GlowGuide 

GlowGuide  is a Python-based skincare recommendation system that generates personalized skincare routines using pandas and a CSV dataset based on skin type, concern, and age.

## Features
- Personalized skincare routines
- Morning and night skincare sections
- Weekly treatments
- Ingredient conflict warnings
- Age-based recommendations
- CSV-based skincare product database

## Technologies Used
- Python
- Pandas
- CSV
- VS Code

## Project Structure

GlowGuide/
│
├── app.py
├── logic.py
├── products.csv

## How to Run

Run the following command in terminal:

```bash
python app.py
```
